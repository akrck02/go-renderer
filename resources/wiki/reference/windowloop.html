windowloop

import "github.com/akrck02/go-renderer/windowloop"

Package windowloop runs a GLFW window’s main loop for any drawing backend (OpenGL, Metal): the window’s events, input, drawing on demand, the fixed-step update clock, frames asked for while the window is being resized, the pointer’s shape and lock. A backend only has to draw and show a frame.
