Core

Package What it is
scene The retained scene: nodes, meshes, materials, instances, levels of detail, the environment (sun, sky, fog, water, wind, snow) and the overlay (labels, header, notices, a free drawing)
viewer The interactive explorer: Run for programs that animate, Edit for programs that change the scene in answer to the person; options and flags
input A snapshot of the keyboard, mouse and touch screen at each step; claims, the clipboard, the pointer’s shape, frames asked for
camera Orbit, walking and map controllers; the ray through a pixel
draw2d A list of flat shapes in layout pixels, which the backends paint over everything
loaders glTF 2.0 with the renderer’s extras
graphics Vec4, Mat4, transformations and projections, the shaders’ sources
models The application loop (Application), the camera, and the immediate-mode Renderer contract
scene/sample A made-up island that uses every feature, needing no files

Platforms and internals

Programs rarely use these directly: viewer and go-ui’s window choose and drive them.

Package What it is
opengl The OpenGL 4.1 backend: the window, the scene renderer, the flat renderer
opengl/overlay Lays the overlay out as quads of one atlas: fonts, icons, the text measurer
metal Metal on macOS: flat and scene windows and renderers
gles Renderers written once for OpenGL ES: WebGL2 in browsers, Android
browser A canvas as the window, built with GOOS=js GOARCH=wasm
android The program as a NativeActivity: window, touches, keyboard, screen reader, built with GOOS=android
windowloop The GLFW window loop OpenGL and Metal share
frameloop The fixed-step clock every loop shares
sceneplan What a frame of a scene draws, worked out once for every backend

Conventions

These hold across every package.

Topic Rule
Axes y is up; the ground is the x–z plane; north is −z
Units The scene’s units are yours (metres, kilometres); some defaults scale with the scene’s size
Points and directions A Vec4 with 1 last is a point, with 0 a direction; colours use it as opacity
Matrices Column-major, as OpenGL; a.Multiply(b) applies b first; translation in elements 12, 13, 14
Scene colours Linear RGB(A), 0 to 1, lit and gamma-corrected by the renderer
Screen colours draw2d.Color and the overlay’s tints are as seen on screen, not gamma-corrected
Screen positions draw2d and touches: layout pixels from the top-left corner, multiplied by the screen’s density when drawn. input.State.CursorX/CursorY and viewer.View: window pixels
Time Update functions run at a fixed step (1⁄60 s by default), whatever the frame rate
Goroutines Update and edit functions run on the drawing goroutine: change the scene there, with no locks. From another goroutine, wake the window (opengl.Wake) and hand the change over
Uploads Meshes and instances are uploaded once; set Dirty (or Instances.MarkChanged) after changing them
Zero values A zero field usually means “the default” (FogFar 0 = no fog, VerticalScale 0 = 1); the field’s comment says which
Icons By Lucide name, everywhere
